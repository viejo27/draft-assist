Draft Assist 0.5.3 mejora el scouting de Clash.

- La pestaña Equipo se llena con tu roster de Clash durante la fase de scouting, incluso cuando el lobby normal no lo expone.
- El equipo sigue siendo editable con el seguimiento LCU activo: nombre, orden, comfort, winrate, pool y Pasar top 5. El tablero de draft permanece de solo lectura.
- El tier del rival se lee del endpoint de tiers de Clash y se muestra como Tier IV / III / II / I, en lugar de Tier -1.
- La barra de pestañas queda fija debajo del topbar al hacer scroll.
- El Rival de Clash y la Rival Live pre-champ-select se refrescan automáticamente.
- Correcciones de datos y documentación.

Si tenés 0.5.2, esta actualización se instala desde la app.
